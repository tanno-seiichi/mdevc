# mdevc のヘルプ

mdevc は、Markdown ファイルをプレビューと同じ見た目のまま直接編集できる、Visual Studio Code の拡張機能です。
編集用とプレビュー用の画面が分かれていないので、書式が実際にどう見えるかを確認しながら、そのまま書き進められます。
Windows デスクトップ用の Markdown エディタ mdew の画面を、VS Code の中で使えるようにしたものです。

このヘルプは、編集画面の右クリック→「ヘルプを開く」で、いつでも開けます（読み取り専用です）。

## 開き方

`.md`・`.markdown` のファイルをエクスプローラー等から開くと、mdevc の編集画面で開きます。

テキストとして編集したい時は、エディタの右上の「テキストエディタで開き直す」
ボタンを押します（コマンドパレットの「mdevc: テキストエディタで開き直す」でも同じです）。
テキストエディタから mdevc に戻す時は、右上の「mdevc で開き直す」ボタンを押します。

## 画面の見方

- **編集領域**：文章を書く場所。ここに表示されている内容がそのまま保存されます。
- **ステータスバー**（下端）：左端の「ソースを表示」（ソースモードでは「Markdownを表示」）のボタンで、
  ソースモードと通常の表示を切り替えられます。保存していない変更がある時は「● 未保存」、
  リンクの上にマウスを乗せた時はリンク先を表示します。
- **mdevc アウトライン**（VS Code のエクスプローラーのサイドバー）：今開いているファイルの見出しの一覧
  （[アウトライン](#アウトライン) 参照）。

文書の表示倍率は、**Ctrl++**・**Ctrl+-**・**Ctrl+0**（100%に戻す）、または **Ctrl+マウスホイール**（編集領域の上で）
で変えられます。文字・画像をまとめて拡大・縮小します。ステータスバー等の大きさは変わりません。

画面の明るさ（ライト・ダーク）は、VS Code の配色（「ファイル」→「ユーザー設定」→「テーマ」）
に合わせて自動で切り替わります。

## 基本操作

| 操作 | 方法 |
|---|---|
| 上書き保存 | `Ctrl+S`（VS Code の「ファイル」→「保存」） |
| 名前を付けて保存 | `Ctrl+Shift+S`（VS Code の「ファイル」→「名前を付けて保存...」） |
| 元に戻す・やり直し | `Ctrl+Z`・`Ctrl+Y` |
| 閉じる | `Ctrl+W`（VS Code のタブを閉じる） |

保存していない変更がある時は、タブの名前の横に「●」が付きます。閉じる時の確認、
ほかのアプリでファイルが変更された時の読み直しも、VS Code のテキストファイルと同じです。

### 編集していない部分はそのまま保存される

mdevc は、見出し・段落・箇条書き・表・コードブロックといったまとまり（ブロック）ごとに、
実際に編集したブロックだけを保存時に書き直します。触っていない部分は、読み込んだ時の書き方（余白や改行の位置など）
がそのまま保たれます。そのため、開いて保存しただけで差分だらけになる、といったことが起きにくくなっています。

## 書式の書き方

編集領域に、見た目そのままで書式が反映されます。

| 書きたいもの | 入力方法 |
|---|---|
| 見出し | 行頭で `#` に続けてスペース（`#`〜`######` で見出し1〜6） |
| 引用 | 行頭で `>` に続けてスペース |
| 太字 | `**太字にしたい文字**`、または文字を選んで `Ctrl+B` |
| 斜体 | `*斜体にしたい文字*`、または文字を選んで `Ctrl+I` |
| 取り消し線 | `~~取り消し線にしたい文字~~`、または文字を選んで `Alt+Shift+5` |
| 下線 | 文字を選んで `Ctrl+U`（保存すると `<u>…</u>` になります） |
| ハイライト | `==ハイライトしたい文字==` |
| インラインコード | `` `コードにしたい文字` ``、または文字を選んで `` Ctrl+Shift+` ``（日本語キーボードでは `Ctrl+Shift+@` の位置） |
| 箇条書き | 行頭で `-`（`*`・`+` でも可）に続けてスペース |
| 番号付きリスト | 行頭で `1.` のように数字＋ピリオドに続けてスペース |
| チェックボックス | 箇条書きの項目の先頭、または表のセル（見出しの行以外）の先頭で `[ ]`（未チェック）または `[x]`（チェック済み）に続けてスペース（表のセルでは、スペースは無くてもよい） |
| 水平線 | `---` と入力して Enter |
| コードブロック | 行頭で `` ``` ``（言語名を続けてもよい：`` ```csharp ``）と入力して Enter |
| 表 | `|見出し1|見出し2|` のように入力して Enter |
| リンク | `[表示する文字](URL)`、または `<https://...>` |
| メールアドレスのリンク | `<name@example.com>` |

これらの記号は、閉じ側の記号を打ち終えた時点で、見た目の書式に変換されます。保存する時には、
元の Markdown の記法に戻ります。

文字を選んで右クリックすると、太字・斜体・下線・取り消し線・インラインコード・ハイライトを、
メニューから設定・解除できます（設定されている書式には ✓ が付きます）。

文字を選んで右クリック→「リンクにする…」で、リンク先の URL を入力して、選んだ文字をリンクにできます。

右クリック→「ページトップに戻る」で、文書の先頭を表示します（カーソルも先頭に移ります）。ソースモードでも使えます。

段落・見出しの上で右クリック→「見出し」から、見出しのレベル（見出し1〜6）を変えたり、
本文に戻したりできます（今のレベルには ✓ が付きます）。

### 箇条書き・リストの操作

- 項目の途中で **Enter**：次の項目を追加
- 項目の途中で **Shift+Enter**：項目の中で改行（新しい項目にはなりません）
- **Tab**：字下げ（入れ子のリストにする）
- **Shift+Tab**：字下げを戻す
- 空の項目で **Enter**：リストから抜ける（入れ子の項目なら、1段上に戻ります）
  - リストの途中で1段上に戻ると、後ろの項目はその項目の入れ子になります（Markdown の決まり）。
    戻った項目に文字を書けば、その下に後ろの項目が並びます。空のままにしたい時は、
    その空の行で **BackSpace** を押すと、元の形に戻ります
- 入れ子のある項目の先頭で **BackSpace**：項目の文字を1つ上の行につなげ、
  入れ子の項目も前の項目の下へ移します（Wordと同じ）

チェックボックスはクリックで、チェック・未チェックを切り替えられます。
チェックボックスの項目の先頭でBackSpace を押すと、チェックボックスを外して通常の項目に戻ります。

表のセル（見出しの行以外）の先頭にも、チェックボックスを置けます。
セルの先頭で `[ ]` または `[x]` と打つと（後ろのスペースは無くてもかまいません）、
チェックボックスになります（ファイルには、セルの先頭の `[ ]`・`[x]` として保存されます。GitHub 等の他のアプリでは、
`[ ]` の文字のまま表示されます）。セルの先頭で BackSpace を押すと、チェックボックスを外します。

### 見出し・引用の操作

見出しの先頭で BackSpace を押すと、通常の段落に戻ります。引用の先頭で BackSpace を押すと、引用を解除します。
引用の最後の空の行で Enter を押すと、引用から抜けます。

### コードブロックの操作

コードブロックの中では、Enter は改行として働きます。**Tab** でタブ文字を入れられます。コードブロックから抜けるには、
上下の行をクリックしてください。

### 貼り付け

ほかのアプリからコピーした文字は、Markdown として読み、見出し・リスト・表・太字などの書式にして貼り付けます。
Claude などのチャット・Web ページ・Word などからコピーした書式付きの内容は、
Markdown の書き方に直して貼り付けます（箇条書き・番号付きリスト（入れ子も）
・見出し・太字・斜体・取り消し線・リンク・インラインコード・コードブロック・引用・表・画像。
文字の色や大きさなどの飾りは捨てます）。書式にしたくない時は、
**Ctrl+Shift+V**（または右クリック→「書式なしで貼り付け」）で、文字のまま貼り付けます。コピーした画像は、
画像として貼り付けます（[画像](#画像) 参照）。

### 段落中の改行

ソースの1行の終わり（空行を挟まない、単純な改行）をどう表示するかは、設定の「段落中の改行」
で選べます（[設定](#設定) 参照）。既定は「空行が入るまで改行しない」で、空行を挟まない改行は空白として扱われ、
段落は画面の幅で折り返して表示されます（VSCode の Markdown プレビューと同じです）。「ソースの通りに改行する」
に切り替えると、ソースの改行がそのまま見た目の改行になります。どちらの表示でも、保存する内容は変わりません。

段落の途中で **Shift+Enter** を押すと、その場で改行します（保存すると、ソースの改行になります）。

## 表（テーブル）

`|見出し1|見出し2|` のように入力して Enter を押すと、表になります（見出しの行と、空の行が1行作られます）。
右クリック→「表を挿入…」で、行数（見出しの行を含む）と列数を指定して、
空の表を作ることもできます（右クリックした段落の後ろに作られます。空の段落の上なら、その段落が表になります）。

- **Tab**・**Shift+Tab**：次・前のセルへ移動します。最後のセルで Tab を押すと、行を追加します。
- **Ctrl+Enter**：下に行を挿入します。
- 表のセルの上で右クリックすると、行・列の挿入・削除、表をコピー、表を削除ができます。

## Excel・他のアプリとの連携

- **Excel から貼り付け**：Excel で選んだ範囲をコピーして貼り付けると、表になります（1つ目の行が見出しの行になります）
  。範囲の中に画像があれば、画像も一緒に貼り付けます。タブ区切りの文字の貼り付けも、表にします。
- **Excel へ貼り付け**：右クリック→「Excel用にコピー」で、選んだ見出し・段落・箇条書きの項目などを、
  Excel で1行1セルに分かれて、太字などの見た目も保ったまま貼り付けられる形でコピーします。表の中では、
  選んだセルの範囲をコピーします。右クリック→「表をコピー」（表のセルの上）では、表全体を罫線付きでコピーします。
  画像も一緒に貼り付けられます（画像は一時的なファイルとして書き出すので、コピーしたら早めに貼り付けてください）。
  Excel では、画像が下の行の文字に重なって表示されることがあります。表の中の画像は、
  Excel に貼り付けられないことがあります。
- **通常のコピー**（`Ctrl+C`）：Word などのほかのアプリには、見出し・表などの書式付きで貼り付けられます。
  mdevc・mdew どうしでは、見出し・リスト・表などの書式のまま貼り付けられます。

## 画像

`![説明](images/a.png)` の形のほか、`<img src="images/a.png" width="200">` の形（HTML のタグ）
で書いた画像も表示します。相対パスの画像は、開いているファイルのフォルダを基準にして表示します（`C:\...`
のような絶対パスで書いた画像は表示されません）。

クリップボードにコピーした画像（スクリーンショット等）は、`Ctrl+V` で貼り付けられます。貼り付けた画像は、
**貼り付けた時にすぐ**、編集中のファイルと同じフォルダの `<ファイル名>.images` フォルダに `clipboard_image_1.png`
のような名前で保存されます（同じ名前のファイルがある場合は、連番を付けて重ならないようにします）。
保存していない新しいファイルには、画像を貼り付けられません。

画像をダブルクリックするか、右クリック→「画像を開く」を選ぶと、Windows で関連付けられた既定のアプリ（フォト等）
でその画像を開きます。

## リンク

リンクは青字＋下線で表示され、**クリック**で開きます（Ctrl は不要です）。リンクの文字を編集する時は、
矢印キーでカーソルを移動してください。リンクの上にマウスを乗せると、ステータスバーにリンク先が表示されます。

- `http://`・`https://`・`mailto:` のリンク：既定のブラウザ・メールソフトで開きます。
- 文中にそのまま書いたメールアドレス（`name@example.com`）も、mailto のリンクとして表示されます（GitHub と同じ。
  ファイルには書いたまま、`< >` を付けずに保存されます）。入力した時は、後ろに空白・句読点等を打つか、
  Enter を押した時にリンクになります。
- `#見出し` のリンク：文書の中のその見出しへ移動します。
- 相対パスの Markdown ファイル（`other.md` 等）へのリンク：VS Code の別のタブで、そのファイルを開きます。

## アウトライン

VS Code のエクスプローラー（サイドバー）の「mdevc アウトライン」に、今開いているファイルの見出しが、階層付きで
一覧表示されます（mdevc の画面を見ている時だけ表示されます）。見出しをクリックすると、編集領域のその位置まで
移動します。長い文書で目的の場所をすぐに見つけたい時に便利です。

下の階層の見出しがある見出しは、左の「›」をクリックすると、その下の見出しを折りたためます（もう一度クリックすると
広がります）。ビューの右上のボタンで、すべての見出しをまとめて折りたためます。折りたたんだ状態は、文章を編集しても、
ソースモードに切り替えても保たれます。

検索している時は、見つかった箇所を含む見出しの文字が強調され、今の箇所の見出しが選択されます。

VS Code 標準の「アウトライン」（Outline）は、mdevc の画面の見出しを表示できません（VS Code の制限です）。

## 検索と置換

**Ctrl+F**（検索）・**Ctrl+H**（置換）で、画面の右上に検索と置換のバーを表示します（VS Code
のテキストエディタの検索と同じ操作です）。文字列を範囲選択してから開くと、その文字列が検索する文字列に入ります。
入力するたびに探して、「今の箇所 / 見つかった数」を表示します。今の箇所はオレンジ、
ほかの見つかった箇所は黄色で表示します。

| 操作 | キー・ボタン |
|---|---|
| 次を検索・前を検索 | `Enter`・`Shift+Enter`（`F3`・`Shift+F3`、↓・↑のボタン） |
| 置換の入力欄を開く・閉じる | 左端の「›」のボタン（`Ctrl+H` でも開きます） |
| 置換して次へ | 置換の入力欄で `Enter`（「置換」のボタン） |
| すべて置換 | `Ctrl+Alt+Enter`（「すべて置換」のボタン） |
| 大文字と小文字を区別する・単語単位・正規表現 | `Alt+C`・`Alt+W`・`Alt+R`（「Aa」「ab」「.*」のボタン） |
| 閉じる | `Esc`（✕のボタン） |

「すべて置換」は、Markdown のソースに対して置き換えます（「**」やリンクの URL なども対象になります）。
置き換えた結果は保存していない変更になります。

VS Code の **Ctrl+Shift+F**（フォルダーを指定して検索）・**Ctrl+Shift+H**（フォルダーを指定して置換）も、
そのまま使えます。置換した結果は、開いている mdevc の画面にもすぐに反映されます。ただし、検索結果から開いた時は、
その箇所へは移動しません（ファイルの先頭を表示します）。その箇所を見たい時は、検索と置換のバー（Ctrl+F）
で探してください。

## ソースモード

ステータスバーの「ソースを表示」（または右クリック→「ソースモードに切り替え」）で、
Markdown のソースをそのまま編集するモードに切り替えられます。書式を気にせず、文字として一括で編集したい時に使えます。
ステータスバーの「Markdownを表示」（または右クリック→「Markdownモードに切り替え」）で、元の表示に戻ります。

切り替えた時は、切り替える前に見ていた段落などが、同じように一番上に見える位置を表示します。ソースモードでも、
保存・検索と置換が使えます。

## 設定

VS Code の「ファイル」→「ユーザー設定」→「設定」（`Ctrl+,`）で「mdevc」を検索すると、次の設定を変えられます。
変えた設定は、開いているすべての編集画面にすぐに反映されます。

| 設定 | 内容 |
|---|---|
| 表示スタイル | 「GitHubスタイル」（既定）と、Visual Studio Code の Markdown のプレビューに似せた「VSCodeスタイル」（Segoe UI の 14px、見出しの下の淡い線、下線なしのリンク、赤い字のコード、縦の線の無い表等） |
| 文字の色 | 「くっきりした色」（既定。ほぼ黒）と、少し薄い灰色で線が細く見える「目にやさしい色」（暗い配色の時は、それぞれ明るい色・少し暗い色） |
| 本文の幅 | 「読みやすい幅にする（最大 884px）」（既定。本文は最大 884px の幅で中央に表示）と、「編集ペインの幅に合わせる」（列の多い表を広く表示したい時等） |
| 段落中の改行 | 「空行が入るまで改行しない」（既定）と「ソースの通りに改行する」（[段落中の改行](#段落中の改行) 参照） |

## ショートカット一覧

| キー | 動作 |
|---|---|
| `Ctrl+S` | 保存 |
| `Ctrl+F` / `Ctrl+H` | 検索と置換のバー |
| `F3` / `Shift+F3` | 次を検索 / 前を検索（検索と置換のバーを開いている時） |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直し |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | 太字 / 斜体 / 下線 |
| `Alt+Shift+5` | 取り消し線 |
| `` Ctrl+Shift+` `` | インラインコード |
| `Ctrl+Shift+V` | 書式なしで貼り付け |
| `Ctrl+Enter`（表の中） | 下に行を挿入 |
| `Tab` / `Shift+Tab` | 字下げ / 字下げを戻す（リスト）、次 / 前のセル（表） |
| `Shift+Enter` | 段落・項目の中で改行 |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | 拡大 / 縮小 / 表示倍率を100%に戻す（Ctrl+マウスホイールでも拡大・縮小） |

上の表にないキー（`Ctrl+P`・`Ctrl+Tab`・`Ctrl+W`・`Ctrl+Shift+P`・`F5` 等）は、
VS Code のショートカットとして動きます。

## 困ったときは

- 動作がおかしいと感じた時は、一度ファイルを保存してから、タブを閉じて開き直してみてください。
- 動作の記録は、VS Code の「表示」→「出力」（`Ctrl+Shift+U`）で「mdevc」を選ぶと表示されます。
- 編集画面で **F12** を押すと、編集画面の開発者ツールが開きます（画面側の調査用）。
