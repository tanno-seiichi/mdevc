# VSCode機能拡張の設定画面

1. 「ファイル」→「ユーザー設定」→「設定」を開きます（`Ctrl+,`）。
2. 上の検索欄に「mdevc」と入力します。

次の 4 つの項目が出てきます。変えるとすぐに、開いている mdevc の画面に反映されます。

| 設定 | 選べる値 |
| --- | --- |
| 表示スタイル（Doc Style） | GitHubスタイル（既定）／VSCodeスタイル |
| 文字の色（Text Color） | くっきりした色（既定）／目にやさしい色 |
| 本文の幅（Doc Width） | 読みやすい幅にする（最大 884px。既定）／編集ペインの幅に合わせる |
| 段落中の改行（Soft Break） | 空行が入るまで改行しない（既定）／ソースの通りに改行する |

拡張機能開発ホスト（F5 で開いたウィンドウ）で試しているときは、そのウィンドウの設定画面で変えてください。

ライト・ダークの配色は、ここではなく VS Code のテーマに合わせて自動で切り替わります。
